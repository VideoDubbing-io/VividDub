# Code of Conduct

## Our Pledge

We are committed to providing a respectful and harassment-free environment for
everyone participating in this project.

## Expected Behavior

- Be respectful and constructive.
- Focus feedback on the work and the public project goals.
- Use clear, professional communication.

## Unacceptable Behavior

- Harassment, abuse, or discriminatory language.
- Publishing private information without permission.
- Spam, intentionally disruptive behavior, or bad-faith participation.

## Enforcement

Project maintainers may remove comments, close issues, or restrict
participation when behavior is inconsistent with this code of conduct.

Concerns can be reported to support@vividdub.com.
