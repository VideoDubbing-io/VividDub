# Contributing

Thanks for your interest in VividDub.

This repository contains public product-facing materials. Contributions should
focus on clear wording, broken links, documentation fixes, and other public
information improvements.

## Guidelines

- Keep product descriptions accurate and public-safe.
- Do not include private credentials, customer data, internal repository names,
  or non-public operational details.
- Keep changes focused and easy to review.
- Use pull requests for proposed updates.

## Pull Requests

Before opening a pull request:

1. Check that links in changed documentation work.
2. Check that no private information is included.
3. Summarize what changed and why.

For business inquiries or product questions, contact support@vividdub.com.
