# Security Policy

## Reporting a Vulnerability

If you believe you have found a security issue in VividDub public materials,
please contact support@vividdub.com.

Please include:

- A clear description of the issue.
- Steps to reproduce or verify the issue.
- Any relevant links, screenshots, or public references.

Do not open a public issue for vulnerabilities that could expose private data
or operational risk. We will review reports and follow up through the contact
channel used for the report.
